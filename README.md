# Linux Infrastructure Automation

Collection of Ansible automation projects developed to standardize, manage, and scale Linux infrastructure operations.

## Overview

This repository contains Infrastructure-as-Code solutions for common Linux administration and platform engineering tasks, including:

* CIFS share provisioning
* Ubuntu patch management
* Salt Minion onboarding
* Ubuntu repository standardization

These automations were designed to reduce manual effort, improve consistency, and support large-scale Linux environments.

## Technologies

* Ansible
* Linux
* Ubuntu
* SaltStack
* CIFS / SMB
* APT Package Management

## Projects

### CIFS Share Provisioning

Automates CIFS share creation, mount configuration, and persistent filesystem management.

### Ubuntu Patch Management

Standardizes patching workflows while protecting critical infrastructure packages from unintended upgrades.

### Salt Minion Onboarding

Automates Salt Minion installation, configuration, registration, and service management.

### Ubuntu Repository Standardization

Automates repository migration and standardizes package source configuration across Linux servers.
